# МИР № 1 — Живая цивилизация (новая версия)
Браузерная 3D-игра на React + Three.js, адаптирована для мобильного Safari.
## Cloudflare Pages
- Root directory: `new-world`
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 20+
Игра сохраняет ресурсы и постройки в localStorage. Никакой регистрации не требуется.
